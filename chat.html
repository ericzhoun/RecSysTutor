How it works. Your question is embedded and matched against 973 chunks of the course (modules, the paper atlas and all 244 library posts) using pgvector similarity search; the best passages plus your conversation history go to kimi-k2.6. The chips under each answer show which modules were retrieved and how closely they matched. Every source chip is a link — click it to read the lesson or the library article the answer was drawn from. Labels beginning ML@Scale #N are items in the 244-post reading library (a separate collection from the course's own M1–M11 modules, so an “#N” there is not a lesson number); labels beginning M1–M11 are course modules. Answers take roughly 5–20 seconds to write — the status line and the animated placeholder show the request is still working, so please don't close the tab. The full interactive course — lessons, widgets, exercises — lives on this site; a DeepTutor CLI integration also exists in the repo under deeptutor/.
