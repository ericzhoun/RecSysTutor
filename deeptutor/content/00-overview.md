# RecSysTutor — course overview

An interactive course on recommender systems for machine-learning engineers, assembled from the “Be a happy and strong coder” blog archive and the Awesome-Deep-Learning-Papers ads knowledge graph.

## Structure

- **m0** — Orientation
- **m1** — The funnel and its foundations
- **m2** — Candidate generation / retrieval
- **m3** — Ranking & feature interaction
- **m4** — Sequential & generative recommenders
- **m5** — Multi-task learning
- **m6** — Case study: Twitter’s recommender
- **m7** — Practical toolkit & capstone
- **m8** — Paper atlas: the Ads & RecSys collection

## How to study with DeepTutor

Ask for explanations grounded in these notes, request quizzes per module, or ask for a study path:
```bash
deeptutor chat --kb recsys-course -t rag
deeptutor run deep_question "Module 2 candidate generation" --kb recsys-course --config num_questions=5
deeptutor run mastery_path "recommender systems, beginner to HSTU" --kb recsys-course
```
